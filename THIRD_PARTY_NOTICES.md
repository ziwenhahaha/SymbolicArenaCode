# Third-Party Notices

This artifact contains adapters for, and selected source files from,
third-party symbolic regression projects. Each bundled project remains subject
to its upstream license and copyright notices.

The bundled algorithm directories include:

- Deep Symbolic Optimization (DSO)
- End-to-End Symbolic Regression (E2E-SR)
- FePySR
- GPLearn
- iMCTS / MCTS-4-SR
- JAX-based symbolic regression components
- LLM-SR and DRSR
- Operon / PyOperon integration code
- PySR integration code
- QLattice integration code
- RAG-SR
- SymbolFit
- TPSR / NeSymReS components
- uDSR

Upstream license files and notices retained inside the corresponding algorithm
directories take precedence over this summary. Dataset provenance is recorded
in each `core-50/*/metadata.yaml` file and in `core-50_datasets.csv`.
